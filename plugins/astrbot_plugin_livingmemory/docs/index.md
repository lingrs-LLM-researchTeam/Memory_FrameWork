## Framework installation

Framework 1.1.0 installs one `astrbot_plugin_livingmemory` plugin with an optional internal learning module. Read the root `README.md` in the complete framework source bundle for installation, migration, current defaults, commands and build instructions.

The [English documentation](/en/) preserves upstream feature and architecture references. Upstream version numbers, installation instructions and release automation describe the original project; the framework root README governs this maintained distribution.
